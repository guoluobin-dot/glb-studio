# GLB Studio + Hermes

本地运行的 AI 直播切片工作台。桌面端负责上传、审片、出片，Hermes 负责把直播内容分析成结构化爆款记忆，让越用越准。

**完全离线运行**，不上传你的视频。AI 推理走本机 Ollama（短片段）或你自己的云端 API（长直播）。

---

## 一、它做什么

一场两小时的直播进来，出去的是几条剪好的成片加字幕。中间所有判断都由本地模型完成：

1. **转写** —— 语音识别成带时间戳的逐句稿，识别行业热词（人名、品牌、术语）
2. **全场拆解** —— 逐句判断这段是教学、是互动寒暄、还是导流，给出钩子和爆点
3. **爆款记忆库** —— 每个 IP 老师一个独立记忆库，攒下"什么开头留人、什么话术留人"的经验
4. **自动粗剪** —— 按记忆挑出值得留的句子，剪掉寒暄和"点点关注"这类废话
5. **人工精修** —— 桌面端逐句改，跨段删字，只看字幕就能剪
6. **出片** —— 重新编码保证切点精确，拼成成片，生成字幕文件

## 二、目录结构

这是一个仓库装两个东西：

```
.
├── src/            桌面端（Electron + React）
├── resources/      图标、安装包配置
├── hermes/         分析引擎（纯 Node.js，独立运行）
└── scripts/        运维脚本
```

**为什么两个东西放一个仓库？** 桌面端会调用 Hermes，两者必须一起升级。分开管迟早出现版本对不上。

**注意 `hermes/` 是快照，不是运行时那份。** 你在本机改代码不会自动更新这里，需要：

```bash
node scripts/sync-hermes.mjs          # 把本机运行版同步进仓库（自动脱敏）
node scripts/sync-hermes.mjs --check  # 只看有没有差异，不写入
```

同步脚本会自动把本机绝对路径、用户名、真实 IP 名替换成占位符，并排除 `config/secrets.local.json`、`data/`、`upload/`、`node_modules/`。**先跑 `--check` 看一眼再写入。**

## 三、安装运行

桌面端：

```bash
npm install
npm run dev
```

Hermes（独立跑，一般不用手动起，桌面端会拉起）：

```bash
cd hermes
npm install
node src/hermes.js
```

默认监听 `127.0.0.1:17841`。

## 四、模型

短片段走本机 Ollama，长直播走云端。切换逻辑在 `hermes/src/llm/engine-selector.js`。

| 用途 | 模型 |
|---|---|
| 文字分析 | `qwen3:8b-chat` |
| 画面理解 | `qwen2.5vl:7b` |

**本机显存 8GB 时本地只能吃 8192 上下文的输入。** 超过这个量必须走云端 —— 硬塞会爆显存，或者静默截断导致分析质量下降。`engine-selector` 会算这个账，别手动绕过。

API 密钥写在 `hermes/config/secrets.local.json`，这个文件不在版本控制里。示例：

```json
{
  "GEMINI_API_KEY": "sk-...",
  "DEEPSEEK_API_KEY": "sk-..."
}
```

## 五、数据与隐私

所有数据在你自己机器上：

- 视频文件：不复制、不上传。Hermes 只登记路径，按需读取
- 数据库：`hermes/data/hermes.db`（SQLite），含转写稿、分析结果、学习反馈
- 爆款记忆库：桌面端在用户数据目录下，按 IP 隔离
- API 密钥：`hermes/config/secrets.local.json`，环境变量优先

`.gitignore` 已排除密钥、数据库、运行数据和构建产物。

**发版或贴图前请先跑一遍扫描**，确认没有密钥和真实姓名混进仓库。

## 六、已知边界

这些是设计上就有的取舍，不是待修的 bug：

- **8GB 显存跑不了长直播本地分析。** 30 分钟、16000 字左右已自动转云端。这是显存物理限制，调配置只会让它崩。
- **字级精确切片要重新编码。** 为了切点落在准确的毫秒上，牺牲了速度，体积也会变大。快速模式可以退回 `-c copy`。
- **粗剪目前是逐句判断，不是逐字。** 字→时间的换算已经实现，但让模型逐字挑内容收益不大、容易出错。
- **练声类教学内容可能被预筛误判为"循环啰嗦"跳过。** 预筛的重复度规则对声乐教学不友好，这类直播的记忆积累目前不可靠。
